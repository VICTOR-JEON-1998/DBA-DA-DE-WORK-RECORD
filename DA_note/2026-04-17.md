# Dataware 활용한 model 신청 방법

## What

- 현재 DA로서 DB 메타 정보를 관리하고 있습니다.
- DA# , META#을 활용해 특정 테이블의 스키마를 변경할 때의 DA 프로세스를 기록하기 위해 글을 작성합니다.
- DATAWARE 라는 제품을 사용하고 있는데, 이를 활용하여 설명드리겠습니다.
- 제품별로 약간의 기능 차이는 있을 수 있지만 전반적인 흐름인 대동소이 할것으로 생각합니다.#CASE :  TABLE1 테이블에 MID_COLLUMN 라는 컬럼을 중간에 넣도록 추가하기.
- DB를 MSSQL로 사용하고 있다면, 컬럼을 추가할 때 맨 뒤에 단순히 컬럼을 추가하느냐, 아니면 중간 순서로 추가하느냐는 다릅니다.
- MSSQL은 중간에 컬럼을 추가하는 기능을 지원하지 않기 때문에 중간 순서에 컬럼이 들어가야 한다면
- DBA로서 기존 테이블의 스키마를 참고하여 , 컬럼이 중간에 추가된 신규 테이블을 생성하고

## How

- 기존 테이블의 데이터를 신규 테이블로 이관하고, 테이블의 이름을 변경하는 작업이 필요합니다.
- 현재는 백업 테이블을 만들고, 테이블의 스키마 정보만 새로 따고, 기존 테이블을 삭제하고 -> 신규 테이블을 기존 테이블 이름으로 만드는 방식을 사용하고 있습니다.테이블/컬럼 조회를 활용하여 수정이 필요한 테이블의 DB 위치를 확인하고, 모델 통합 검색을 통해정확한 주제영역 위치를 확인할 수 있다.주제영역 위치를 확인하였으면 MODEL5 를 활용하여 모델을 내리고 -> 변경하고 -> 올리고 -> 신청할 수 있다모델 신청이 완료되어야 COMMIT이 된 상태라고 볼 수 있다.
- ERD를 파악하여 논리 모델의 ERD 위치를 파악하면 더 편하게 신청할 수 있다.현재는 논리모델로 관리를 한다.
- 논리모델의 변경 -> 물리모델의 반영 순이다.
- 주의할 점은 논리모델에서 컬럼을 중간에 추가했다고 하더라도 물리모델을 보면 맨 뒤로 컬럼이 추가되어 있기 때문에,CRTL + G 를 눌러서 편하게 물리모델로 넘어가서 컬럼순서 초기화를 해줘야 논리모델의 형상에 맞게 물리모델의 컬럼 순서가 적용된다.
- 내리기 이후에 변경이 끝났으면 올리기 -> 모델 신청 순서로 진행하면 된다
- 신청을 완료하면 DATAWARE에서 신청중인 상태를 확인할 수 있다.
