# 자동화 업무 경험

- ERP 데이터파기관리 작업관리 상세 복사 자동화
- 배경
- 소스(dev)와 타겟(prod) ERP 환경 간에 데이터파기관리 화면의
- 작업관리 상세
- 데이터를 동기화해야 하는 작업이 반복적으로 발생. 한 칸씩 수동 입력하는 대신 콘솔 스크립트로 자동화함.
- 소스:
- https://dev-erp.mistodev.com/cm/admin/sysmng/histmng/cmdatadestruct#CM00042000
- 타겟:
- https://erp.mistobrand.com/cm/admin/sysmng/histmng/cmdatadestruct#CM00042000
- 핵심 파악 내용
- 그리드 구조
- 화면은
- AUI Grid
- 컴포넌트 기반으로 일반
- <input>
- 태그가 없어 DOM 직접 조작 불가.
- AUIGrid._getInstance(id)
- API로 그리드 인스턴스를 가져와야 함.
- 그리드 ID
- 파기대상 테이블 목록:  #aui-grid-wrap-aebcaa6f-a3e6-4db3-9d67-1d1d8ea5ea25
- 작업관리 상세:         #aui-grid-wrap-4aeaa8b2-a740-4ed3-b941-b3a6861d3f31
- 그리드 ID는 페이지 배포 환경에 따라 바뀔 수 있음.
- 바뀐 경우 아래 진단 코드로 재확인:
- AUIGrid.getCreatedGridAll(); // ID 목록 확인
- 작업관리 상세 필드명 (mskgSeCd 코드값)
- 화면 표시
- 실제 코드값
- NULL처리
- "10"
- 마스킹
- "20"
- 데이터 필드 구조
- {
- colNm,        // 컬럼명
- colExpn,      // 컬럼명(Comment)
- mskgSeCd,     // 마스킹구분 코드 ("10" or "20")
- mskgStrtDgt,  // 마스킹시작
- mskgPrcsCnt,  // 마스킹개수
- mskgCharVal,  // 마스킹문자
- rmrk          // 비고
- }
- 저장 시 주의사항
- setGridData()
- 로 데이터를 넣으면
- rowStatus
- 가 변경됨으로 마킹되지 않아
- 저장 불가
- .
- 반드시
- removeRow()
- +
- addRow()
- 방식을 사용해야 저장 가능.
- 사용 방법
- 순서
- 소스 탭
- 에서 복사할 행 클릭 → 작업관리 상세 로드 확인
- F12 콘솔 →
- allow pasting
- 입력 → Enter (최초 1회)
- STEP 1 코드
- 실행 → 팝업에서
- Ctrl+A
- →
- Ctrl+C
- → 확인
- 타겟 탭
- 에서 같은 행 클릭
- F12 콘솔 →
- STEP 2 코드
- 실행 → 팝업에
- Ctrl+V
- → 확인
- 저장 버튼 클릭
- 팁:
- 콘솔에서
- ↑
- 화살표를 누르면 이전 코드가 다시 나옴. 두 번째 행부터는 붙여넣기 없이
- ↑
- → Enter만 하면 됨.
- 스크립트
- STEP 1 — 소스 탭 (데이터 추출)
- (function(){
- var ids=AUIGrid.getCreatedGridAll();
- var g=null;
- ids.forEach(function(id){
- var inst=AUIGrid._getInstance(id);
- if(!inst)return;
- var d=inst.getGridData();
- if(d&&d.length>0&&d[0].hasOwnProperty('mskgSeCd'))g=inst;
- });
- if(!g){alert('행을 먼저 클릭하세요!');return;}
- var data=g.getGridData();
- var clean=data.map(function(r){
- return{colNm:r.colNm,colExpn:r.colExpn,
- mskgSeCd:r.mskgSeCd,
- mskgStrtDgt:r.mskgStrtDgt||null,
- mskgPrcsCnt:r.mskgPrcsCnt||null,
- mskgCharVal:r.mskgCharVal||null,
- rmrk:r.rmrk||null};
- });
- prompt('Ctrl+A 후 Ctrl+C로 전체 복사하세요:', JSON.stringify(clean));
- })();
- STEP 2 — 타겟 탭 (데이터 입력)
- (function(){
- var json=prompt('STEP 1에서 복사한 JSON을 붙여넣으세요:');
- if(!json)return;
- var srcData;
- try{srcData=JSON.parse(json);}
- catch(e){alert('올바른 데이터가 아닙니다. STEP 1을 다시 실행하세요.');return;}
- if(!srcData[0]||!srcData[0].hasOwnProperty('mskgSeCd')){
- alert('데이터 형식이 올바르지 않습니다.');return;
- }
- var ids=AUIGrid.getCreatedGridAll();
- var g=null;
- ids.forEach(function(id){
- var inst=AUIGrid._getInstance(id);
- if(!inst)return;
- var d=inst.getGridData();
- if(d&&d[0]&&d[0].hasOwnProperty('mskgSeCd'))g=inst;
- });
- if(!g){alert('행을 먼저 클릭하세요!');return;}
- var cur=g.getGridData();
- for(var i=cur.length-1;i>=0;i--)g.removeRow(i);
- srcData.forEach(function(row){g.addRow(row);});
- alert('✅ '+srcData.length+'행 입력 완료!\n저장 버튼을 눌러 저장하세요.');
- })();
